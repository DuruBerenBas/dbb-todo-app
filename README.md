# 📝 DBB To-Do App

Simple and clean command-line To-Do application written in Python.  
Users can add tasks, list them, mark them as completed, and delete tasks.  
All data is stored in `tasks.json`, so tasks are kept even after the app is closed.

---

## 🚀 Features

- ➕ Add new tasks  
- 📋 List all tasks  
- ✔️ Mark tasks as completed  
- 🗑️ Delete tasks  
- 💾 Stores tasks in `tasks.json` for persistence  
- 🔧 Simple and beginner-friendly Python file structure
